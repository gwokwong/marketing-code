## 这是什么

小旺好评助手是一款运行在微信里的门店口碑营销工具。商家在后台配置好店名、招牌菜、服务项目和卖点后，生成一张**营销二维码**贴在店内；顾客消费后扫码，勾选真实体验，即可**一键生成自然、真实、千人千面**的好评文案、探店笔记与朋友圈文案，复制后直接发布到大众点评、小红书、抖音和朋友圈。

> 告别「顾客嫌麻烦不写评价、员工引导没提成干不动、花钱刷评有封店风险」的恶性循环。

## 核心功能

| 功能 | 说明 |
|------|------|
| **营销码一店一码** | 每店生成独立营销码，额度、到期、套餐挂主码，子码（员工码）自动上溯统计 |
| **顾客扫码即用** | 无需下载 App、无需注册，微信扫一扫即可使用 |
| **一键出稿，千人千面** | 顾客勾选「上菜快」「口味正宗」等真实标签，自动组装成自然文案，每条都不一样 |
| **四大内容类型** | 好评评价 / 探店笔记 / 朋友圈文案 / 短视频脚本 |
| **员工专属码** | 每位员工一个专属码，谁引导的顾客、产出多少条评价，数据清清楚楚 |
| **多门店管理** | 连锁店统一管理各分店码与额度，素材知识库全店共享 |
| **异步生成 + 额度统计** | 生成任务异步处理，失败自动回滚额度，消费记录全程可审计 |
